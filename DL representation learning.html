Robust Representation Learning

December 2025| On Low-Resolution Images via Self-Distillation
Python PyTorch Vision Transformers (ViT-Small) DINO (Self-Distillation) NYU Greene HPC (A100 GPUs) Pandas NumPy

Project Overview

In this project, I tackled a constrained Self-Supervised Learning (SSL) challenge: training a visual encoder from scratch on 500,000 unlabeled images without using any external pre-trained weights. The core constraint was extreme data limitation - images were resized to a low resolution of 96×96 pixels, and the model parameter budget was capped at 100M.

While standard industry approaches often rely on massive compute and high-resolution data (224px+), I engineered a pipeline that learns semantic features from low-information inputs. I successfully demonstrated that Vision Transformers (ViT) significantly outperform traditional CNNs in this regime by preserving spatial fidelity, achieving 66.5% accuracy on Mini-ImageNet evaluation using only frozen features.

Tech Stack: PyTorch, Vision Transformers (ViT-Small), DINO (Self-Distillation), NYU Greene HPC (A100 GPUs), Pandas, NumPy.

The Challenge: Why Standard Methods Failed

My initial approach involved hybrid SSL designs using ResNet-50 backbones with contrastive objectives (MoCo v2, BYOL). However, I encountered severe instability and representation collapse. Through failure analysis, I identified the mathematical bottleneck:

  • Aggressive Downsampling: Standard ResNets reduce spatial dimensions by a factor of 32. For a 96×96 input, this results in a trivial 3×3 feature map.
  • Information Loss: This 3×3 grid was insufficient to capture complex spatial relationships required for scene understanding tasks.
  • Contrastive Instability: Contrastive methods were hypersensitive to batch size, which was constrained by the available GPU memory.

The Solution: ViT + DINO

To overcome the spatial information loss, I pivoted to a ViT-Small architecture trained with the DINO objective.

1. Architecture Choice: I utilized a ViT-Small with a patch size of 8. Unlike the CNN's 3×3 output, this resulted in a 12×12 grid (144 tokens), preserving significantly richer spatial detail.

2. Self-Distillation: I implemented a Teacher-Student framework where the Teacher network is an Exponential Moving Average (EMA) of the Student. This removed the need for negative pairs, stabilizing training on smaller batches.

3. Multi-Crop Augmentation: I engineered an asymmetric data pipeline using 2 Global crops (for the Teacher) and 6 Local crops (for the Student). This forced the network to learn "local-to-global" semantic correspondences.

Key Results

I evaluated the model by freezing the encoder and training a simple Linear Probe (Logistic Regression) on the features. The results validated the architectural pivot, beating random baselines significantly.

Conclusion & Takeaways

This project highlighted that architecture matters as much as the objective function. In low-resolution regimes, the inductive bias of CNNs (pooling) can be destructive. By switching to a patch-based Transformer approach (P=8), I demonstrated that we can learn robust, transferable representations even without labels or massive datasets. The success of self-distillation over contrastive learning in this setting suggests that clustering-based objectives are more sample-efficient for training from scratch.
