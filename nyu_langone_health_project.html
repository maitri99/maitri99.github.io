Motivation: The "Hallucination" Problem

Transplantation medicine relies on decades of fragmented clinical trials and evolving guidelines. Clinicians face two major challenges when using modern AI tools to synthesize this data:
1. Hallucination: Generic LLMs (like ChatGPT) frequently invent citations, which is dangerous in high-stakes clinical settings.
2. Recency Bias: Standard search algorithms prioritize new papers, ignoring foundational historical studies.
3. Privacy: Uploading patient context to cloud-based models violates privacy standards (HIPAA).

The Solution

We built a local, privacy-preserving Retrieval-Augmented Generation (RAG) pipeline. Unlike standard systems that ingest everything, we utilized Bibliometrics (Reference Publication Year Spectroscopy - RPYS) to curate the corpus, ensuring the model only retrieves from historically significant and scientifically validated papers.

System Architecture

The pipeline consists of three distinct engineering stages:

  • A. Bibliometric Data Curation: Ingested 15,000+ records via PubMed/OpenAlex APIs. Used RPYS to identify "citation peaks" and filter down to 3,500+ seminal PDFs.
  • B. Advanced Extraction: Implemented a "Fusion Extraction" strategy using pypdfium2 for digital PDFs and DeepSeek OCR for scanned historical documents.
  • C. Two-Stage Retrieval:
    - Recall: Indexed 20,000+ chunks using FAISS (Bi-Encoder).
    - Precision: Re-scored candidates using a Cross-Encoder (ms-marco-MiniLM) to filter out distractors. Only the Top 10 clinically relevant chunks were sent to the LLM.

Results: Local vs. Cloud

We benchmarked our local Qwen2.5 model against GPT-4o on 32 complex clinical queries. Our specialized pipeline achieved higher citation accuracy.

Metric Generic Cloud LLM (GPT-4o) Our Local Pipeline (Qwen2.5)
Citation Accuracy 61.9% 67.7%
Faithfulness (RAGAS) 86.1% 89.4%
Privacy Data Leaves Premise 100% Offline / Local
Cost $$$ (Per Token) Free (Open Weights)

The system performed best on "Complex/Guideline" questions (e.g., immunosuppression protocols), achieving 97.7% Answer Relevancy. We validated these results using Natural Language Inference (NLI), finding a 54% positive correlation between our citation metrics and logical entailment.
