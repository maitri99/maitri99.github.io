Deep Learning Resume Parser

December 2021| Converting unstructured PDF resumes into structured datasets using Computer Vision (Detectron2) and OCR.

The Challenge

I led a team of 4 engineers to develop an automated resume parsing solution for Keystone Inc.. In the recruitment industry, filtering thousands of resumes is a massive bottleneck. Traditional parsers often fail when resumes have creative layouts, double columns, or graphics because they rely on simple text extraction (Regex).

Our project solved this problem by treating the resume as an image first. By using Object Detection to visually segment the document into distinct regions (Education, Skills, Work Experience), we extracted text with context, resulting in highly structured data ready for downstream analytics.

Python Detectron2 PyTorch OCR (Tesseract) LayoutParser Pandas

Methodology & Architecture

The solution is an end-to-end pipeline that transforms raw PDFs into a structured CSV database.

1. Preprocessing & Annotation:
The resume books were converted from PDF to high-resolution images. To train the custom model, dataset of resumes were manually annotated, drawing bounding boxes around key regions (Work Experience, Education, Skills, etc.).

2. Object Detection (The Core):
Utilized Detectron2 (a PyTorch-based library by Meta Research) to train a Faster R-CNN model. This model learns the visual structure of a document, allowing it to distinguish between a "Skills" section and a "Work History" section purely based on layout.

3. Content Extraction:
Once the bounding boxes are predicted, the pipeline crops these specific regions and passes them through an OCR engine (EasyOCR/Tesseract). This ensures that text is extracted within context, avoiding the common issue of mixing up text from two different columns.

4. Structured Output:
The extracted text is mapped to its category and saved as a CSV/JSON file, creating a searchable database of candidates.

Key Features & Challenges Solved

1. Layout Invariance: Unlike regex-based parsers, this model handles two-column layouts and non-standard formatting effectively.

2. Custom Named Entity Recognition (NER): instead of generic NER, this treats whole sections as objects, preserving the relationship between a job title and its description.

3. Automated Structuring: capable of processing a batch of PDFs and outputting a clean CSV for HR analytics.

Results & Impact

The model achieved high precision in segmenting complex layouts, successfully handling multi-column resumes that standard parsers missed. The final output is a clean, structured CSV file containing categorized data for every candidate, enabling automated filtering and analytics for HR teams.
