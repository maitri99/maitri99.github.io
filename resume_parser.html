Deep Learning Resume Parser

A sophisticated pipeline designed to convert unstructured PDF resumes into structured datasets using Computer Vision. Unlike traditional parsers that rely on regex, this project treats resumes as images to accurately segment complex layouts.

The Challenge

Traditional text extraction fails on double-column resumes or creative formats. The goal was to build a model that understands the visual layout of a document before extracting text.

Methodology

1. Preprocessing & Annotation

Converted PDF resumes to high-res images and manually annotated bounding boxes for key regions (Education, Work Exp, Skills) to create a custom training set.

2. Object Detection (Detectron2)

Utilized Meta's Detectron2 (Faster R-CNN) to train a model capable of visually identifying and classifying distinct sections of a resume.

3. Content Extraction

Cropped the predicted regions and passed them through an OCR engine to extract raw text, maintaining the context of each section.

4. Structured Output

Mapped extracted text to a unified schema, exporting the data into a clean CSV format ready for HR analytics or candidate matching.
